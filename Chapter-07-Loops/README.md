## 📓 Core Topics Covered
* **Loops**: Control structures that repeat a block of code while a condition is met.
* **While Loop**: Iterates as long as the test condition remains `True`.
* **For Loop**: Iterates over a sequence (list, tuple, string) or a range of values.
* **range() Function**: Generates a sequence of numbers (e.g. `range(start, stop, step)`).
* **For Loop with Else**: Executes an optional `else` block when the loop finishes normally (without running into a `break`).
* **Loop Control Statements**:
  * `break` — Terminates the loop prematurely.
  * `continue` — Skips the current iteration and jumps to the next test condition.
  * `pass` — A null statement acting as a placeholder where syntax requires code but no action is desired.

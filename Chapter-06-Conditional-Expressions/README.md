## 📓 Core Topics Covered
* **Conditional Statements**: `if`, `elif` (else if), and `else` blocks that form a decision ladder.
* **Relational Operators**: `==`, `>=`, `<=`, `>`, `<`, `!=` used to compare values.
* **Logical Operators**: `and`, `or`, `not` used to combine multiple conditional statements.
* **Elif Clause**: Allows checking multiple conditions sequentially until one matches.
* **Important Design Notes**:
  * Any number of `elif` statements can be used.
  * Only one block of code in the ladder is executed (the first expression that evaluates to `True`).
  * The `else` block is optional and executes if no conditions match.

## 📓 Core Topics Covered
* **Modules**: Code libraries that can be imported to extend program capabilities.
  * *Built-in Modules*: Libraries pre-packaged with Python (e.g., `os`, `sys`).
  * *External Modules*: Libraries developed by third parties and installed via `pip` (e.g., `pyjokes`, `pyttsx3`).
* **pip**: The package installer for Python, used to download and manage packages from the PyPI repository.
* **Python REPL**: Read-Eval-Print Loop, an interactive shell used to run snippets of code instantly (e.g., using Python as a calculator).
* **Comments**: Text ignored by the compiler/interpreter, used to document code.
  * *Single-line comments* (`#`)
  * *Multi-line comments* (`'''` or `"""`)

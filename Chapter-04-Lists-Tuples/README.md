## 📓 Core Topics Covered
* **Lists**: Mutable collections of items.
  * *List Indexing*: Accessing and modifying values via 0-based indices.
  * *List Methods*:
    * `.sort()` — Sorts list in ascending order.
    * `.reverse()` — Reverses order of list.
    * `.append()` — Adds item to the end.
    * `.insert(index, val)` — Inserts value at specific index.
    * `.pop(index)` — Deletes and returns item at index.
    * `.remove(val)` — Deletes given element from list.
* **Tuples**: Immutable collections of items (elements cannot be modified after creation).
  * *Tuple Methods*:
    * `.count(val)` — Returns occurrences of value.
    * `.index(val)` — Returns first index of value.

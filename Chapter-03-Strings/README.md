## 📓 Core Topics Covered
* **String Slicing**: Accessing parts of a string using indexes (`string[start:end]`).
* **Slicing With Skip Value**: Stepping through a string with custom increments (`string[start:end:step]`).
* **String Functions**:
  * `len()` — Gets string length.
  * `.endswith()` — Checks if string ends with substring.
  * `.count()` — Counts occurrences of characters/words.
  * `.capitalize()` — Capitalizes the first character.
  * `.find()` — Finds index of a word/character.
  * `.replace()` — Replaces old word/character with new.
* **Escape Sequence Characters**: Formatting strings with characters like `\n` (newline), `\t` (tab), `\'` (single quote), `\\` (backslash).

## 📓 Core Topics Covered
* **Variables**: Containers for storing data values.
* **Data Types**: 
  * Integers (`int`)
  * Floating-point numbers (`float`)
  * Strings (`str`)
  * Booleans (`bool`)
  * NoneType (`None`)
* **Rules for Choosing an Identifier**: Valid variable names in Python (e.g. alphanumeric characters and underscores, cannot start with a number).
* **Operators in Python**:
  * *Arithmetic Operators*: `+`, `-`, `*`, `/`, etc.
  * *Assignment Operators*: `=`, `+=`, `-=`, etc.
  * *Comparison Operators*: `==`, `>`, `<`, `>=`, etc.
  * *Logical Operators*: `and`, `or`, `not`
* **type() Function**: Used to find the data type of a variable.
* **Typecasting**: Converting one data type to another (e.g., string to float).
* **input() Function**: Used to accept input from users as strings.

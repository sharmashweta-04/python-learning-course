## 📓 Core Topics Covered
* **New Python Features**:
  * *Walrus Operator* (`:=`): Assigns values to variables as part of a larger expression.
  * *Type Hints & Definitions*: Explicitly stating expected variable and return types.
  * *Match Case*: Structural pattern matching (similar to switch-case).
  * *Dictionary Merge & Update Operators*: Merging dictionaries using `|` and `|=`.
* **Exception Handling**: Handling runtime errors gracefully using `try`, `except`, `else`, and `finally` blocks.
* **Raising Exceptions**: Throwing errors intentionally using the `raise` keyword.
* **If \_\_name\_\_ == "\_\_main\_\_"**: Checks if the script is executed directly or imported as a module.
* **global Keyword**: Declares that a variable inside a function is local to the global scope.
* **enumerate()**: Loops over an iterable and tracks both element index and item.
* **List Comprehensions**: Elegant, one-liner syntax to create lists from existing iterables.
